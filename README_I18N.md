# 日本語・英語の表示切り替え

## 変更内容

- 画面、ナビゲーション、フォーム、選択肢、確認モーダル、エラー表示、ツールチップ、読み上げラベルの固定文言を `src/i18n/locales/ja.ts` / `en.ts` に集約しました（1,468項目）。
- 初回は端末の言語にかかわらず日本語です。ヘッダーの「日本語 / English」で切り替え、選択を端末内に保存します。スマートフォンでは「JA / EN」で表示します。
- 言語を切り替えても画面を再マウントせず、入力中の値やエディタの記事を保持します。
- カレンダー、エディタのプレースホルダー、WebView内の固定メッセージにも翻訳を接続しました。
- 日本語のAPIエラーは、画面へ表示する際に対応する辞書の文言へ変換します。
- 求人本文、記事HTML、会社名、氏名、メッセージ、評価コメントなどの登録内容は自動翻訳しません。給与は表示時に英語表記へ変換し、保存形式は維持します。
- ステータス、雇用形態、報酬方式などのAPI・DB保存値は日本語の既存形式を維持しています。追加のDB変更はありません。

## 主なファイル

| ファイル | 役割 |
| --- | --- |
| `src/i18n/index.ts` | i18next初期化、日本語デフォルト、英語リソース |
| `src/i18n/locales/ja.ts` | 日本語の原文 |
| `src/i18n/locales/en.ts` | 同一キーの英語訳 |

| `src/i18n/source.ts` | 保存値を変更しないための日本語参照・補間 |
| `src/i18n/native.tsx` | Text・入力・ボタン・Alertの共通表示処理 |

## 文言を追加する場合

日本語・英語の `messages` に同じキーを追加し、画面では `tText('キー')` を使用します。日本語を保存値として使う選択肢や状態比較では `sourceText('キー')` を使用してください。

画面コンポーネントは `useLocaleVersion()` で言語変更を購読します。React Compilerが外部翻訳関数の結果を保持しないよう、購読するコンポーネントには `"use no memo"` を設定しています。プロジェクト全体のReact Compiler設定は維持しています。

登録内容を表示する `Text` / `BodyText` / `SectionTitle` には `localize={false}` を指定できます。`TextInput` の値そのものは翻訳しません。動的メッセージの氏名などを補間する場合は、`sourceFormat` の第3引数で、その値のキーを翻訳対象外に指定してください。

## 確認コマンド

```sh
npm run check:i18n
npm run typecheck:i18n
npx expo export --platform web
```

`check:i18n` は日本語・英語のキーと補間変数の一致、英語訳の未翻訳チェック、日本語デフォルト、API値の不変性、ユーザー入力の保護を確認します。型検査は現行のsrcを対象とし、既存の未使用mockDataと退避ディレクトリは対象外です。

Web版はAPIをテスト用応答に置き換えて、主要画面の英語表示、言語の保持、求人編集途中の言語変更、カレンダー、掲載上限の確認と非公開保存を確認しています。実サーバーとの結合確認とiOS/Android端末での動作確認は含みません。
